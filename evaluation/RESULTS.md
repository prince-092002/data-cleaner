## Honest metrics: all injected errors

- **Detection recall:** share of injected errors the engine fixed, changed, flagged, listed as "left alone", or named as a problem for that column in the profile.
- **Fix recall:** share of injected errors that end up correct AND in the standard form (real empty cell, plain number, ISO date, true/false, tidy text). A deleted value cannot be restored, so missing values can be detected but never fixed.
- Injections that changed nothing (original equals injected) are not errors and are left out.
- **Ambiguous dates** (03/04/2024) are counted as detected, not fixed: the engine cannot know the order and asks the user. If the user picks the right order they are all fixed; that figure is in the last column.
- The held-out batch uses a different seed and a file with region abbreviations the engine was never tuned on. It is the figure to quote.
